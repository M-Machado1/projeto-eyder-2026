## Consulta Meteorológica

 Aplicação para consulta de informações meteorológicas de localidades.
 ## Funcionalidades 
 Pesquisar uma cidade ou localidade, visualizar as condições meteorológicas atuais e consultar uma previsão
resumida para os próximos dias.
## API
Open-Meteo API.
